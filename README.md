# Mehndi-Verse (Zari & Henna Atelier)

A world-class luxury Mehndi Artist Marketplace and bridal appointment booking platform. Connects brides, clients, and event planners with certified master Mehndi artists worldwide.

## ✨ Features

- **Luxury Design & Royal Aesthetics**: Deep Emerald Green, Royal Burgundy, Champagne Gold, and Warm Ivory palettes with double-bezel glassmorphism cards.
- **Master Artist Marketplace**: Filter by destination cities (*Dubai, London, New York, Delhi, Lahore, Mumbai*), price range slider, experience, and artistic styles.
- **Instagram-Inspired Artist Profiles**: High-definition portfolio masonry with zoom lightbox, before/after 48-hour stain preview, tiered service packages, and verified bridal reviews.
- **Interactive Booking Wizard**: 4-step appointment scheduler with add-on bundles, date & time slot selection, venue details, escrow deposit calculator, and celebratory confetti confirmation.
- **Artist SaaS Studio**: Analytics overview, bookings manager (Accept/Decline/Complete), portfolio uploader, package editor, calendar blocker, and VIP Pro search boost.
- **Customer Dashboard**: Track active bridal appointments, manage wishlist artists, and communicate via in-app messenger.
- **AI Bridal Henna Consultant**: Interactive 4-step quiz matching wedding outfits, ceremony types, and coverage preferences to curated styles and vetted artists.
- **100% Certified Organic Guarantee**: Zero PPD, chemical-free henna formulas across all listed artists.

## 🚀 Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons, Canvas Confetti
- **State & Storage**: React Context API, LocalStorage persistence layer
- **Architecture**: Modular component design, dual-bezel nested structures, responsive mobile bottom app bar

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
